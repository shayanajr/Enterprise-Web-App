# وب‌اپ تعاملی اجاره خودرو Enterprise

این نسخه بر اساس ۳۷ فریم نهایی در بخش `1049:3238` فایل فیگما ساخته شده است. چیدمان موبایلی، تصاویر خودرو، آیکون‌ها، فونت Plus Jakarta Sans و رنگ‌های طرح در آن استفاده شده‌اند. برای مقصدهایی که صفحه‌ای در فایل مبنا نداشتند صفحه تازه‌ای ساخته نشده است.

## اجرای سریع در ویندوز

فایل ZIP را کامل استخراج کنید و روی **start.bat** دوبار کلیک کنید.

راه دیگر: فایل **dist/index.html** را در Chrome یا Edge باز کنید. همه تصاویر، فونت‌ها و کدها داخل پوشه هستند؛ برای اجرای رابط نیازی به نصب پکیج یا اتصال اینترنت نیست.

## اجرا با Node.js

با Node.js نسخه ۲۲ یا بالاتر، ترمینال را در پوشه پروژه باز کنید:

```bash
npm start
```

سپس آدرس زیر را باز کنید:

```text
http://localhost:3000
```

به `npm install` نیازی نیست. برای تغییر پورت، `node server.mjs --port 8080` را اجرا کنید یا متغیر محیطی `PORT` را تنظیم کنید. در مک و لینوکس می‌توانید `./start.sh` را هم اجرا کنید.

## ورود آزمایشی

شماره آزمایشی متناسب با کشور انتخاب‌شده وارد کنید؛ برای آمریکا ۱۰ رقم مثل 4155550142 و برای ایران ۱۰ رقم بدون صفر اول مثل 9123456789. کد ورود آزمایشی **482916** است. گزینه `From Messages` نیز همین کد را وارد می‌کند. دکمه ارسال تا کامل‌شدن شماره و دکمه تأیید تا کامل‌شدن شش رقم غیرفعال می‌مانند. کد اشتباه، حالت خطای طراحی‌شده را نمایش می‌دهد.

## نسخه اصلاح‌شده ۲٫۱

- کد رابط فقط HTML، CSS و JavaScript است و به React یا نصب پکیج نیاز ندارد.
- لوکیشن، تاریخ و ساعت به‌صورت مودال با پس‌زمینه تار باز می‌شوند؛ تب‌های ورود و ساعت، همان پنل را به‌روزرسانی می‌کنند.
- تمام ۱۵ عکس رستری به WebP تبدیل شده‌اند: حدود ۹۱٪ کاهش حجم. آیکون‌ها و گرافیک‌های برداری SVG باقی مانده‌اند.
- نوار پایین و کارت مبلغ مرور رزرو ثابت‌اند و فقط بخش لازم اسکرول می‌خورد.
- حرکت خورشید و نوار روی قوس، ستاره‌های AI، شمارش مبلغ و تأیید موفق با صدای کوتاه اضافه شده‌اند.
- ورود با کد، نقشه و تمام پرداخت‌ها همچنان آزمایشی هستند. صدا بعد از کلیک دکمه تأیید پرداخت فعال می‌شود.

### اصلاحات تکمیلی

- فاصله و ارتفاع دو خط قیمت در جزئیات خودرو از مقادیر فیگما تنظیم شده است.
- پس‌زمینه لوکیشن خاکستری ثابت است. نقشه از همان لایه‌ها و پین‌های فایل استفاده می‌کند؛ تغییر مقصد مسیر قبلی را حذف می‌کند و موقعیت شخص ثابت می‌ماند.
- حالت شب از گرادیان و ماه سفید همان فایل استفاده می‌کند. گزینه‌های ساعت هر تب هم از همان فریم‌ها خوانده می‌شوند.
- حلقه فوکوس OTP فقط روی خانه فعال است؛ فیلد شماره در ابتدا عادی است و هنگام فوکوس سبز می‌شود.
- مشخصات تایپوگرافی و نوشته‌ها دوباره از کامپوننت‌های سکشن پروتوتایپ خوانده شده‌اند. فونت اصلی Plus Jakarta Sans است؛ فونت‌های کیبورد نمایشی و برچسب‌های نقشه نیز محلی هستند.

## امکانات قابل آزمایش

- ورود، ثبت‌نام، ورود مهمان، تکمیل کد، خطای شماره و کد، تایمر ارسال مجدد.
- پروفایل کاربر و مهمان، خروج، تنظیمات و ذخیره انتخاب‌ها در مرورگر.
- انتخاب و جست‌وجوی شعبه، نمایش نقشه طراحی‌شده و انتخاب محل تحویل.
- تقویم تعاملی، انتخاب بازه، تغییر ماه، بازنشانی و انتخاب ساعت صبح، عصر و شب.
- حالت بارگذاری، خطا، نتیجه خالی، فیلترها و مرتب‌سازی.
- جزئیات خودرو، نوع نرخ، انتخاب پوشش و خدمات اضافه با محاسبه مبلغ.
- شبیه‌سازی اسکن گواهینامه، اعتبارسنجی اطلاعات راننده، ویرایش مرحله‌های رزرو.
- جزئیات هزینه، انتخاب روش پرداخت، تأیید رزرو و دانلود رویداد تقویم با فرمت ICS.
- انیمیشن ورود صفحات، شیت‌ها، اسکن، کنترل‌های انتخابی و تأیید؛ رعایت تنظیم Reduce Motion.
- سازگاری با عرض موبایل و نمایش قاب اصلی موبایل در دسکتاپ.

## محدوده نسخه

این پروژه یک **دموی فرانت‌اند تعاملی** است. پیامک، ورود Apple/Google، تشخیص گواهینامه، موتور هوش مصنوعی، پرداخت و ارسال ایمیل به سرویس واقعی متصل نیستند. نقشه همان نقشه ثابت طراحی‌شده در فیگما است. گزینه‌های بدون صفحه مستقل در فایل مبنا، مقصد تازه‌ای ندارند. داده‌ها فقط در مرورگر همین دستگاه ذخیره می‌شوند.

## ویرایش کد

| مسیر | کاربرد |
|---|---|
| `src/app.js` | وضعیت برنامه، مسیرها، ورودی‌ها، محاسبات و تعاملات |
| `src/app.css` | ظاهر کنترل‌ها، چیدمان قاب و موشن‌ها |
| `src/figma-typography.json` | مشخصات متن استخراج‌شده از پروتوتایپ |
| `src/figma-prototype-text-audit.json` | متن و مشخصات تمام ۷۸۸ نود متنی خوانده‌شده در ۳۶ فریم فعلی سکشن |
| `src/screens/` | HTML قابل ویرایش هر ۳۷ فریم با شناسه نود فیگما |
| `src/flows.json` | اتصالات استخراج‌شده از پروتوتایپ |
| `src/screen-manifest.json` | نام، اندازه و شناسه فریم‌ها |
| `dist/assets/` | تصاویر و آیکون‌های محلی و فایل‌های فونت |
| `scripts/build.mjs` | ساخت بسته مستقل از کدهای src |
| `server.mjs` | سرور محلی بدون وابستگی |

بعد از تغییر `src`، دستور زیر را اجرا کنید:

```bash
npm run build
```

خروجی آماده انتشار داخل `dist` قرار دارد. می‌توانید همین پوشه را روی هر هاست استاتیک قرار دهید. تغییر فایل‌های داخل `dist` هنگام ساخت مجدد بازنویسی می‌شود.

## مشاهده مستقیم حالت‌ها

شناسه مسیر را به انتهای آدرس اضافه کنید؛ مثلاً `#home` یا `#filters`.

| دسته | مسیرها |
|---|---|
| شروع و ورود | `#splash`، `#welcome`، `#login`، `#signup`، `#phoneError`، `#otp`، `#otpFilled`، `#otpError` |
| حساب | `#profile`، `#guest`، `#settings` |
| خانه و جست‌وجو | `#home`، `#warning`، `#location`، `#locationSearch`، `#map` |
| تاریخ و ساعت | `#date`، `#dateEmpty`، `#morning`، `#afternoon`، `#evening` |
| خودرو | `#cars`، `#carsFiltered`، `#loading`، `#empty`، `#error`، `#filters`، `#filtersClear`، `#details` |
| رزرو | `#protection`، `#extras`، `#scan`، `#driver`، `#review`، `#price`، `#payment`، `#confirmed` |

برای پاک‌کردن اطلاعات آزمایشی ذخیره‌شده، داده‌های این سایت را از تنظیمات مرورگر حذف کنید یا از پنجره ناشناس استفاده کنید.
